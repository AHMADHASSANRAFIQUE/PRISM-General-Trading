# Prism General Trading — Premium Corporate Website

A production-quality corporate website for **Prism General Trading**, a UAE-based FMCG, vitamins, supplements, and healthcare distribution and marketing company established in 1994.

---

## 🏛️ Business Overview & Approved Facts

- **Established:** 1994 (over 30 years of continuous commercial presence in the UAE)
- **Customer Locations:** 4,000+ active locations across modern trade, traditional trade, pharmacies, and institutional channels
- **Market Coverage:** Nationwide coverage across all seven UAE Emirates (Dubai, Abu Dhabi & Al Ain, Sharjah, Ajman, Ras Al Khaimah, Fujairah, and Umm Al Quwain)
- **Core Categories:** FMCG, Beauty & Personal Care, Skincare & Cosmetics, Vitamins & Dietary Supplements, Health & Wellness, Household Cleaning & Hygiene, and OTC Healthcare Products
- **Corporate Office:** Dubai, United Arab Emirates
- **Telephone:** +971 4 251 5753
- **Inquiries Email:** info@prismintl.co
- **Website Domain:** https://prismintl.co

## 🛠️ Tech Stack & Implementation Details

- **Framework:** Next.js 15 (App Router, React 19)
- **Styling:** Tailwind CSS with bespoke Prism design tokens
- **Typography:** *Playfair Display* (Editorial headings) + *Plus Jakarta Sans* (Executive body copy)
- **Icons:** Lucide React
- **Asset Processing:** Official `Prism_Logo.png` and cropped, optimized brand marks in `public/images/`

## 🚀 Running the Project

```bash
# Run development server
npm run dev

# Build production bundle
npm run build

# Start production server
npm start
```
The website will be running at [http://localhost:3000](http://localhost:3000).
